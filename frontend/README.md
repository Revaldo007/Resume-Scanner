# Frontend — Resume Screening System

React + Vite + Tailwind CSS frontend for the Resume Analysis and
Intelligent Candidate Screening System.

## Setup

```bash
npm install
npm run dev
```

The dev server runs at http://localhost:5173 and expects the backend
API to be running at http://127.0.0.1:8000 (see ../backend/README.md
or the base URL in src/services/api.js).

## Build

```bash
npm run build
```
